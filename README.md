## 🚀 Features
- 🔐 JWT-based User Authentication & Authorization
- 🛍️ Full Product Listing with Search & Filter
- 🛒 Shopping Cart with Quantity Management
- 📦 Order Placement & Order History Tracking
- 👑 Admin Panel — Manage Products, Orders & Users
- 💳 PayPal Payment Integration
- ⭐ Product Reviews & Star Ratings
- 📱 Fully Responsive UI (Mobile + Desktop)

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React.js, Redux Toolkit, React Router, Bootstrap |
| Backend | Node.js, Express.js, REST APIs |
| Database | MongoDB, Mongoose |
| Auth | JWT, bcryptjs |
| Payment | PayPal REST API |
| Tools | Git, GitHub, VS Code, Postman |

---

## ⚙️ Setup & Installation

```bash
git clone https://github.com/Mohitpradhan6/ecommerce-fullstack.git
cd ecommerce-fullstack
npm install
cd frontend && npm install
npm run dev
```
